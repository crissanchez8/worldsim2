# Prompts de fase

Un prompt auto-contenido por fase. Para arrancar una fase:

1. Abrí una **sesión nueva** de Claude Code en la carpeta del proyecto (`worldSim2`).
2. Pegá el contenido completo del prompt de la fase (o escribí: *"Ejecutá `docs/prompts/P03-planeta.md`"*).

Claude lee `CLAUDE.md` y `docs/STATUS.md` por su cuenta, escribe el BRIEF y espera tu aprobación
antes de tocar código. Si la fase ya estaba en curso, retoma desde el handoff de `STATUS.md`.

Los prompts se **refrescan al cerrar la fase anterior** (paso 9 del protocolo) con lo aprendido.
La versión vigente siempre es la de este directorio.
